# 架构选型：Host / 安全运维 · 自建跨境合规 · 海外仓 API · 支付宝微信双分区 · 论坛

> 面向 TypixNode（开源硬件、跨境、卖家在中国大陆、已选择"继续自建"）。数据来源为 2026-06 公开资料，价格/政策以各官方为准。

---

## 1. Host / 架构：Shopify vs 现状，安全与运维谁更低？

### 1.1 两者的 Host 模型
| | **Shopify** | **我们现状** |
|---|---|---|
| 架构 | 全托管 SaaS 店铺 + 主题/Liquid + App | Astro 静态站 + **Cloudflare Workers**(SSR API) + **D1**(订单) + Stripe + Resend |
| 你要维护的服务器 | **无**（Shopify 全包） | **无**（CF 全球边缘，serverless，无服务器/无补丁） |
| 切换成本 | 从自建迁过去＝**架构完全改变**，现有代码基本作废 | — |

> 关键：**两者都是"无服务器/托管型"，没有传统服务器运维**。区别在"应用层"谁负责。

### 1.2 安全
- **支付安全**：两者都不让你碰信用卡号——Shopify 用 Shopify Payments/网关，我们用 **Stripe 托管结账**。PCI 负担都极小。
- **基础设施安全**：Shopify 自带 DDoS/WAF/TLS/合规；我们用 **Cloudflare** 同样自带 DDoS/WAF/TLS。
- **应用层安全**：Shopify 把应用层漏洞、合规、风控也包了（更省心）；我们方案这部分要自己负责，但核心风险点（支付、CDN）已分别托管给 Stripe / Cloudflare。

### 1.3 运维成本
- **Shopify**：运维≈0，但有**月费 $39 起 + 抽成**；功能/客服/合规全托管。
- **我们**：运维也≈0，**成本近乎免费**（CF 免费额度 + 仅 Stripe 手续费），但功能要自己写、应用层安全自己担。

### 1.4 结论
- **纯运维**：两者都很低。
- **安全省心度**：Shopify 略胜（应用层 + 合规免责全包）。
- **成本 / 可控 / 开源调性**：自建明显胜。
- **Shopify 明显优势**：成熟电商功能全套、App 生态、稳定性与合规免责、上线快、7×24 客服。
> 对你（4 款产品、起步期、开源品牌、要可 hack）：**自建的低成本+可控 > Shopify 的省心**，安全短板可由 Stripe + Cloudflare 补齐。

## 2. 自建 + 跨境合规：海外仓代发 API 候选

> 这些都能对接**我们现在的自建站**（REST/GraphQL + webhook），不依赖 Shopify。

### 2.1 海外仓履约（你寄货到仓，它代发）
| 方案 | 类型 | 仓库 | 价格(约) | API | 适合 |
|---|---|---|---|---|---|
| **ShipBob** ⭐ | 3PL（自带仓） | 全球 50+（美/加/英/欧/澳） | $2.5–5/单 | REST + webhook | **跨境 DTC、多区域（首选）** |
| Easyship | 发货软件 | 对接亚洲 3PL（Floship/Whiplash Asia）等 | 免费档起 | API | **国际化强、落地成本/关税计算** |
| Shippo / EasyPost | 发货 API | 不带仓（你/3PL 出货） | 按面单 | **开发者友好、最易集成** | 自己或第三方仓打单 |
| ShipStation | 发货工作流 | 不带仓 | $25–200+/月 | API | 多渠道、批量面单 |
| Flexport | 3PL | 仅美国 5 仓 | 按重量，**月最低$5000** | 直连 | 美国为主 + 海运进口 |
| Floship / Whiplash Asia | 亚洲跨境 3PL | 香港/亚洲 | 咨询 | API | 从中国发全球 |

### 2.2 跨境合规 / 关税（DDP，避免买家被海关补税）
| 方案 | 能力 | 模式 | 备注 |
|---|---|---|---|
| **Zonos** ⭐ | 落地成本(关税+税费)计算、**DDP 担保**、HS 编码、217 国 | API/插件，**可自建** | 与任何物流商解耦；有担保(它替你付差额) |
| Easyship | 结账显示落地成本 | 随发货 | 偏发货侧 |
| Global-e / Reach | **Merchant of Record** 全代缴 | 第三方担责 | 通常面向欧美卖家，费率高(~6%) |

### 2.3 推荐组合
**自建站 + ShipBob（履约）+ Zonos（DDP 关税合规）** —— 不上 Shopify 也能做到"备货到海外仓→自动代发→结账含税含关税"。

## 3. 支付：支付宝/微信"公开支付" + 国内/海外双分区

### 3.1 最简接入：用聚合网关，一次集成全搞定
| 网关 | 支付宝/微信 | 中国大陆卖家 | 集成难度 | FX/费率 | 备注 |
|---|---|---|---|---|---|
| **Stripe** | ✅ 内置 Alipay + WeChat Pay | ❌ 账户需海外/香港实体 | **最低**（Checkout 勾选即用，零额外开发） | 卡 2.9%+30¢，FX 较高 | 我们现在就在用 Stripe |
| **Airwallex** ⭐ | ✅ 直连 Alipay/微信/银联 | ✅ 支持大陆业务账户 | 低（API/Drop-in） | 多币种结算、**FX 更便宜(~0.5-1%)** | 对中国卖家最现实 |
| Adyen / PingPong / 连连 | ✅ | ✅(部分) | 中 | 各异 | 备选 |

要点：
- **Stripe 内置支付宝/微信**，用 Checkout 或 Payment Element **在后台勾选即可**，无需单独对接支付宝/微信开放平台——这是"最简单接入"。
- **但 Stripe 不开给中国大陆主体**：你需香港/海外公司。若想用大陆主体就近收款，**Airwallex** 是更现实的首选（同样内置支付宝/微信，且多币种、FX 便宜）。
- 支付宝/微信都支持"海外华人/旅客/大陆用户"扫码支付，结算可落到 USD/HKD/CNY 等。

### 3.2 国内 / 海外双分区设计
一个**地区选择器（中国 / International）**，切换以下维度：

| 维度 | 🌍 海外区 | 🇨🇳 中国区 |
|---|---|---|
| 货币 | USD / EUR / … | CNY |
| 默认语言 | 跟随浏览器（en/ja/…） | 简体中文 |
| 支付方式 | 卡 + Apple/Google Pay + 支付宝/微信(给华人) | **支付宝 + 微信**(+ 银联) |
| 履约仓 | 海外 3PL（ShipBob 就近发） | 国内仓/保税仓/邮政小包 |
| 合规 | Zonos 算 DDP 关税 | 国内直发，无需关税 |

实现方式（在我们自建栈上）：
- 一个 `region` 状态（cookie/选择器，可按 IP/Accept-Language 预选），与现有 `locale` 解耦或联动。
- 结账 API 按 `region` 决定 `currency` 和可用 `payment_method_types`（海外→cards+alipay+wechat；中国→alipay+wechat）。
- ⚠️ 现实提醒：向**大陆消费者**卖跨境实体货涉及清关/税务，建议大陆区走**保税仓/邮政**或先做"预售/导流到代理"；技术上分区不难，难在物流合规。

## 4. 产品论坛（"像 PiSugar 那样"）

> 📌 调研更正：**PiSugar 其实没有独立的 Discourse 论坛**——它用的是 `docs.pisugar.com` 文档站 + GitHub Issues + 树莓派官方论坛做社区。所以"像 PiSugar 那样"如果指的是"有个产品交流地方"，下面给真正的论坛选型。

### 4.1 开源论坛选型
| 方案 | 技术栈 | 资源需求 | 特点 | 适合 |
|---|---|---|---|---|
| **Discourse** ⭐ | Ruby/Rails + Postgres + Redis | ≥2–4GB RAM | 行业标准(GitHub/Docker/CF 都用)、信任等级、强审核、SSO、邮件入帖、多语言 | **正式产品社区（推荐）** |
| Flarum | PHP/Laravel + MySQL | 512MB–1GB | 轻量、好看、省运维、$5 VPS 可跑 | 预算/运维紧的中小社区 |
| NodeBB | Node.js + Redis/Mongo | 512MB+ | 实时 WebSocket、社交感 | 实时讨论/游戏向 |

### 4.2 国内 / 海外访问
- 论坛对**中国访问**要考虑网络与备案：
  - **海外**：Discourse/Flarum 部署在海外 + Cloudflare 前置即可。
  - **国内**：要速度需国内服务器 + **ICP 备案**（需国内主体）；或用国内可访问的托管/镜像。
- **建议不要做两套**：一套 **Discourse** 开"中文板块 / English"分类 + 多语言界面 + CDN 加速，运维只一份。等国内体量大了再加国内镜像/备案站。
- **与主站打通**：Discourse 支持 SSO，主站账号统一登录论坛。
- 托管选项：自托管（$10–20/mo VPS 起，需自己运维 Docker）或官方托管（$50/mo 起，免运维）。

### 4.3 推荐
**Discourse（一套，多语言分类，海外 + Cloudflare）+ SSO 接主站**。预算/运维极简则用 **Flarum**。

## 5. 给 TypixNode 的整体建议（自建路线）

```
站点：Astro + Cloudflare Workers/D1（现状，保留）
支付：Airwallex（大陆主体，内置支付宝/微信）或 Stripe（海外/香港主体）
  └─ 双分区：International(卡+钱包+支付宝/微信) / 中国(支付宝+微信)
履约：ShipBob（海外仓代发）+ Zonos（DDP 关税合规）
社区：Discourse（多语言分类，SSO 接主站，海外+CF）
```
- 成本最低、最可控、最契合开源品牌。
- 安全靠 Stripe/Airwallex(支付) + Cloudflare(基础设施) 托管兜底。
- 等"运营杂事吃掉太多精力"再评估迁 Shopify（届时可设香港实体启用 Shopify Payments 免额外抽成）。
